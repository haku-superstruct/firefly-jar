# Firefly Jar

A tiny game for **Cubby Arcade**, published end to end by an AI coding agent (Muse) as a pipeline test on 2026-11-07.

- **The game:** no words, no losing, no timer. A kid walks a night meadow with the D-pad, swings a net with A to catch fireflies, and watches the jar fill with light. B makes nearby fireflies flutter. The jar count persists through Cubby's save system.
- **Play it standalone:** open `releases/1.0.0/index.html` in a browser (arrow keys + Z), or via GitHub Pages.
- **Cubby feed (catalog):** `https://haku-superstruct.github.io/firefly-jar/catalog.json`
- **Stable release manifest:** `https://haku-superstruct.github.io/firefly-jar/arcade/manifest.json` (schema 2, generated with Cubby's official `cubby_manifest.py`; payload under immutable `releases/1.0.0/`)
